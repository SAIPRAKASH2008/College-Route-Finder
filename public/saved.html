📊 Graph Theory Algorithm Performance Insights

Dijkstra's Shortest Path

Guarantees mathematically optimal path between two specific stops. Complexity: O((V + E) log V).

Prim's Minimum Spanning Tree

Connects all reachable stops using the minimum total road distance with zero cycles. Complexity: O(E log V).

Nearest Neighbour Tour (TSP)

Greedy heuristic visiting every pickup stop and returning to college campus. Complexity: O(V² log V).
